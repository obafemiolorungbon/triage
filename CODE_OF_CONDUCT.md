# Code of Conduct

## Our Pledge

Triage is an open-source project for people building and operating customer
feedback systems. We expect contributors, maintainers, and community members to
treat each other with respect, patience, and professionalism.

## Expected Behavior

- Use welcoming and inclusive language.
- Assume good intent, but be precise when discussing technical problems.
- Keep criticism focused on the work, not the person.
- Respect maintainers' time by providing clear reproduction steps, context, and
  focused pull requests.
- Accept responsibility when a contribution introduces a regression and help
  move the fix forward.

## Unacceptable Behavior

- Harassment, threats, insults, or personal attacks.
- Dismissive comments about identity, background, experience level, or
  communication style.
- Publishing private information without explicit permission.
- Repeatedly derailing issues, pull requests, or discussions.
- Spam, abuse, or promotional content unrelated to the project.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, and other
contributions that violate this code of conduct. For serious or repeated
violations, maintainers may temporarily or permanently restrict participation in
the project.

## Reporting

If you see behavior that violates this code, report it privately through the
project's published maintainer contact channel or GitHub private vulnerability
reporting if the concern has a security component.
